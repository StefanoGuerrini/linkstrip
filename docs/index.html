LinkStrip

A privacy-first macOS menu-bar app that automatically removes tracking parameters from URLs you copy.

Download for macOS View on GitHub

Clipboard cleaning

Monitors the clipboard in the background and strips tracking parameters the moment a URL is copied.

Redirect unwrapping

Extracts the real destination from click-tracking links like link.fndrsp.net.

Editable rules

Ships with 29 default tracking parameters. Add your own or import/export custom rule sets.

Share extension

Right-click any link → Share → LinkStrip to clean it without changing your default browser.

Offline & private

No network access, no analytics, no telemetry. Everything stays on your Mac.

How it works

  • Copy any link to your clipboard.
  • LinkStrip detects the change and removes known tracking parameters.
  • The cleaned URL is written back to the clipboard, ready to paste.
  • Or right-click a link → Share → LinkStrip to clean without changing your default browser.
  • Optionally clean clicked links by setting LinkStrip as your default browser.
